# Expense Counter

I wanted to track my finances but had privacy concerns when using other websites. Turns out, I can build one myself using Django! 

## Login
You can join by logging in or signing up. 
![login](demo/Expense%20-%20Login.png)

## List
You can see a list of all your recent expenses (and add more).
![list](demo/Expense%20-%20List.png)

## Summary
You can see the daily, monthly and yearly summaries of your (questionable) expenses.
![summary](demo/Expense%20-%20Summary.png)
